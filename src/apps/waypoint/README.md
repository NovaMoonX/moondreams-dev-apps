# Waypoint 🗺️

Waypoint is an itinerary-first travel planner for groups. Planning a trip in a shared document starts well, then turns into a wall of text, buried links and hidden costs, and on the day it is hard to find today's schedule or start navigation. Waypoint is a shared planner while you prepare, and a focused view of today once the trip starts.

## How it works

1. Create a trip with a title and dates, and share an invite link or code. An Admin approves each person and picks their role.
2. Fill in the Before the Road checklist and the expected expenses, and split costs among the people involved.
3. Build the timeline: activities, flights, drives, stays and car rentals, grouped by day, each with one-tap directions.
4. Let others suggest changes. Time and place changes are flagged so nobody misses them.
5. When the trip starts, a small Now and Up next pill floats over the main screens, and Overview shows today.
6. Settle up with a running summary of who owes whom.
